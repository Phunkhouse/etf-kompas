# Wireframes

Source files of the rev. 6 wireframes. Two finished HTML documents, built from the same artboards:

| File                           | What it is                                                                                                                                                                    |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `etf-kompas-design-study.html` | The Design Study: the current design as the source of truth (product rules, design system, every screen and state, motion, open data) with a short History section at the end |
| `etf-kompas-board.html`        | The Wireframe Board: every artboard on one canvas, with a motion board                                                                                                        |

Open either in a browser. They need network access only for IBM Plex from Google Fonts.

## Layout

| Path                                                                  | What it is                                                                                              |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `artboards/`                                                          | The 12 original (rev. 1) artboards, unpacked from the canvas export (`<x-dc>` markup, inline styles)    |
| `artboards-v2/`, `artboards-v3/`                                      | Rev. 2 and rev. 3 artboards, generated by `apply_rev2.py` and `apply_rev3.py`                           |
| `artboards-v4/`                                                       | Current artboards (rev. 4 and 5): the original boards updated, plus the new pages and states and the two variant b hero boards |
| `logo/`                                                               | `etf-kompas-logo.svg`, `etf-kompas-logo-dark.svg`, `favicon.svg`, as delivered with the handoff         |
| `apply_rev4.py`, `apply_rev4b.py`, `apply_rev4c.py`, `apply_rev4d.py` | Rev. 4 patches: saving box, phone calculator spacing, stale text, blurred PDF previews                  |
| `apply_rev5.py`                                                       | Rev. 5: the A/B variant b artboards (vb01hero-d, vb02hero-m), copies of the landing pages with the b headline |
| `gen_pages_rev4.py`                                                   | Menu, cookies, privacy policy, 404, unsubscribe, hamburger and footer patches                           |
| `gen_states_rev4.py`                                                  | Form errors, double opt-in e-mail and pages, calculator states, PDF pages 1 and 4, favicon, share image |
| `gen_motion_rev4.py`                                                  | The live motion artboard (inline CSS and JS, loops, reduced-motion switch)                              |
| `bd.py`, `mkboard.py`, `build_study.py`, `doc.css`, `doc.js`          | Build the two HTML documents from the artboards                                                         |
| `export_images.py`                                                    | PNG export of the artboards to `../images/`                                                             |
| `apply_rev6.py`                                                       | Rev. 6: the design review and the data we have now (real rows, fees, calculator result, broker prices, date) |
| `make_rev6.sh`                                                        | The whole chain from `artboards-v2/` to the two HTML files                                              |

## Rebuild

```sh
cd docs/design/wireframes
sh make_rev6.sh
CHROMIUM=/path/to/chromium python3 export_images.py artboards-v4 ../images
```

Needs Python 3 and Playwright with a Chromium (`export_images.py` takes the browser path from `CHROMIUM`, or uses Playwright's own). `artboards-v2/`, `artboards-v3/` and `artboards-v4/` are generated: edit the scripts, not the artboards, and rerun. The chain produces identical outputs when rerun.

The PNG exports in `../images/` are rendered from `artboards-v4/` at 2x, content height, 256 colours. The motion image is a still of a looping artboard.

The old `build.py`, `dump_frames.py`, `png.js` and `etf-kompas-wireframes.html` (rev. 2) were removed in rev. 4. The first two artboard sets stay because the scripts start from them. Artboard `174eb66f` (the old hero table animation) is kept in the files for history only and is not part of the documents.

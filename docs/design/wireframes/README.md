# Wireframes document

`etf-kompas-wireframes.html` is a single-page, designer-style presentation of the 12 wireframe artboards (desktop and phone), ads, design tokens, components, behaviour and open items. Open it in a browser; it needs network access only for IBM Plex from Google Fonts.

| File | What it is |
| --- | --- |
| `etf-kompas-wireframes.html` | The finished document (artboards embedded at native size, real logo SVGs inline) |
| `artboards/` | The 12 original artboards, unpacked from the canvas export (`<x-dc>` markup, inline styles) |
| `logo/` | `etf-kompas-logo.svg`, `etf-kompas-logo-dark.svg`, `favicon.svg`, as delivered with the handoff |
| `build.py`, `doc.css`, `doc.js` | Rebuild: `python3 build.py artboards logo etf-kompas-wireframes.html` |

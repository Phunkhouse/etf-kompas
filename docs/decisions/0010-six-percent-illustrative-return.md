# 0010. 6 % illustrative return, identical for every ETF

Date: 2026-10-10
Status: proposed
Phase: 1

## Context

The calculator shows the cost drag of fees and tax in Kč. It needs an assumed gross return, but the page must not read as a forecast (SPEC §4, §21).

## Decision

Use a gross return of 6 % nominal per year, the same for every ETF so that only costs differ. It is labelled "příklad, ne slib" and is editable in the "Jak počítáme" disclosure.

## Alternatives considered

No other value is recorded in the SPEC. Reasons from SPEC §17.3: the page's message is the cost difference, so the absolute return only scales the numbers, and 6 % is deliberately below long-run US equity history so the page does not sound promissory.

## Consequences

- Wording stays "orientační odhad nákladů", never "you will lose X".
- The assumption must appear in `docs/METHODOLOGY.md` and in the README.
- Changing the default later changes every number on the page, so golden test cases must be regenerated by hand.
